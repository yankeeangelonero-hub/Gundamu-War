# Slice 01 Unit Test — deck-run-model

## What this record proves

That all three deck run models are playable and comparable on identical inputs (AC-1), each is
deterministic (AC-2), a comparison was produced across a fixed matchup set (AC-3), the decision is
recorded as an ADR (AC-4), and a non-deterministic implementation is detectable and was recovered
(AC-5). Run via `node experiments/dual-layer/runmode-check.cjs` over the shared core `sim.js` — the
same engine the browser harness uses — at seed `0xC0FFEE`, rival "KESTREL", four matchups.

## Per-check verification

- **AC-1 — three models playable/comparable on identical inputs.** Setup: four fixed
  (body, deck, rival, seed) matchups. Action: ran each in construction / draw / hybrid changing
  only the model. Signal: the comparison table (each cell a completed duel). Observed: all 12
  cells produced a completed duel and a result. **Verdict: PASS.** Evidence: `runmode-comparison.md`.
- **AC-2 — each model deterministic.** Action: ran each matchup twice per model and byte-compared
  the event stream. Observed: every run1==run2 IDENTICAL (construction 1202–2035B, draw 8476–8645B,
  hybrid 1202–8616B). **Verdict: PASS.** Evidence: paired `draw-aligned-run1/2.json` + the AC-2
  section of `runmode-comparison.md`.
- **AC-3 — documented comparison.** Observed: the matchup × model table with winner, turns, dead,
  whiff, hesit, plus matchup notes. **Verdict: PASS.** Evidence: `runmode-comparison.md`.
- **AC-4 — decision recorded as ADR.** Observed: owner confirmed construction (2026-06-07);
  `Research/Research Documents/adr-2026-06-07-deck-run-model.md` records the chosen model and the
  rationale (legibility, fairness, determinism). **Verdict: PASS.**
- **AC-5 — non-determinism detected and recovered.** Action: ran draw with an unseeded shuffle
  (negative control) five times under one seed. Observed: 5/5 distinct event streams (divergence
  DETECTED); seeded recovery run1==run2 IDENTICAL. **Verdict: PASS.**

## Interpretation

The AC-2 block shows every model reproduces its event stream byte-for-byte under a fixed seed —
including draw, whose seeded shuffle is part of the determinism (BEH-001). The AC-5 block is the
load-bearing guard: with the shuffle deliberately unseeded, five same-seed runs produced five
different streams, proving the diff *detects* non-determinism rather than rubber-stamping it; the
seeded re-run is identical (recovery). The AC-3 table is the decision evidence: construction and
hybrid resolve in 11–18 turns and the misaligned-kite row shows the authored mismatch playing out
(a dead card and a loss), while every draw row times out at 80 turns with 29–39 hesitations — the
deck-as-luck starves the pilot of valid plays. This is why construction was chosen (AC-4 / the ADR).

## US-001 coverage (cited story)

This enabling slice exercises two of US-001's three falsifiable claims directly: determinism
(byte-identical re-runs — PASS) and the dead-card signal (misaligned-kite shows a dead card that
never fired — PASS). The third claim (the debrief never presents an outcome without a concrete
reason) and the full end-to-end build→deploy→watch journey are delivered and verified by the later
feature slices (Hangar / Doctrine bench / Watch + debrief). No US-001 verdict is FAIL.
